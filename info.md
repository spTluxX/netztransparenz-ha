## Netztransparenz Marktwerte

Brings the official monthly EEG market values (Marktwert Solar, Wind on-/offshore, Spotmarktpreis) from the Netztransparenz WebAPI into Home Assistant.

- Five sensors, auto-updated each month
- A configurable **Price** sensor (pick the source via dropdown, choose €/kWh or ct/kWh) ready for the Energy dashboard
- UI config flow — just paste your Netztransparenz API Client-ID / Client-Secret

Requires free API credentials from the [Netztransparenz Extranet](https://extranet.netztransparenz.de) (OAuth Manager).
